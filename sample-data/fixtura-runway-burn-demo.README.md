# Fixtura "Runway burn demo" data set

Generated by Fixtura (si2026-test-generator) to exercise Runway's burn engine
with an **in-progress** contract whose funds run dry before the period ends.

## Files (all one coherent contract — same seed ties them together)

| File | What it is |
|---|---|
| `fixtura-runway-burn-demo.contract.json` | The award — periods, CLINs, labor rates, ceiling vs. obligated, mod history |
| `fixtura-runway-burn-demo.timesheets.csv` | Weekly employee hours booked to the contract's CLINs |
| `fixtura-runway-burn-demo.labor.csv`     | Labor distribution export (bill rate × hours) |

## How it was generated (reproducible)

Fixtura preset generation, **seed 42**, with these opt-in generation options:

```json
{ "pop_in_progress": true, "option_years": 0, "contract_type": "T&M" }
```

- `pop_in_progress` — anchors the base period of performance to the present, so
  the contract is mid-flight (today ≈ week 20 of the 52-week base year) and every
  timesheet week falls inside the period.
- `option_years: 0` — a single base year, so the obligated-vs-ceiling gap lands
  inside the period Runway is watching (a multi-year award spreads obligation
  across option years and doesn't trip).
- `contract_type: T&M` — a labor-hours contract, the burn case.

## Expected tripwire

Base-year labor ceiling ≈ **$8.1M/yr**, but only ≈ **$5.6M** is obligated, so the
funded dollars exhaust around **week 36 of 52**. With today at ≈ week 20, a correct
burn engine should flag CLIN 0001 funding depletion ~16 weeks out — well before
the period-of-performance end date.

To regenerate (or vary the seed/options), load the "Runway burn demo" template in
Fixtura, or POST the options above to `/generate` / `/export`.
